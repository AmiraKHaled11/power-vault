# Power Vault

Grade 8 Lesson 1.6 Indices - a teacher-hosted treasure-chest board for the projector: 24 hidden questions, one column per idea in the book (index form with prime factorisation, multiply and divide, power of a power, zero and negative indices, roots as indices, fractional values), 2-4 groups, manual +/- points for every group.
